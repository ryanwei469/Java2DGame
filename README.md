# Java2DGame

## Overview
This is my first Java 2D game project, created in Eclipse as a part of my independent learning outside of school where I take the IB Computerscience SL course. The current version includes a player walking animation and basic movement controls. The background is currently black but will change soon. Many more features will be added as I continue learning.

## Features
- Player Sprite
- Keyboard Controls (WASD)
- Game loop handling FPS
- Walking Animation
